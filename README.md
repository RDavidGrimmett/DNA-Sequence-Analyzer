# DNA-Sequence-Analyzer
A Python-based bioinformatics pipeline


How did breaking your script into multiple functions help make your pipeline easier to write, read, or debug?
> It makes the code much easier to read. Each code is like a summary of what the function will do. It feels more like a step-by-step approach to coding; finish the first part and make sure it works, then move one to the next. 

Did you encounter any difficulties when integrating the pipeline? If so, how did you resolve them?
> Yes. When trying to implement the final function of the pipeline, I wanted to use a previous function to capture the GC content instead of rewriting the code inside the last function. I wasn't sure how to pass the variables into the function, so this took some trial and error until I figured out the correct order.

Why do you think bioinformatics workflows are frequently structured as pipelines rather than single scripts?
> Due to each part of the pipeline being an isolated function, it allows you to tap into it at any point. Each function or script does a specific task, and this allows you to get a specific set of data instead of the whole script outcome.
